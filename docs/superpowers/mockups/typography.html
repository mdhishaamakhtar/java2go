Typography: four pairings

None of these are on impeccable's lists. Each one has a text face, a heading face and a code face, set on the same Pointers page. The theme switcher stays pinned while you scroll, so you can check each pairing in all four themes.

Look at the code comments and the glyph line at the bottom of each. Comments do a lot of the teaching on this site, and Il1 O0 is where code fonts win or lose.

Pairing 1

The annotated book

Literata · Victor Mono

Literata was designed for Google Play Books, so it's built for long reading on screens, and it has optical sizes that make the big title crisp. Victor Mono's italics are joined-up handwriting, so every code comment reads like a note pencilled next to the code.

Pairing 2

Lively and literary

Alegreya · Alegreya Sans SC · Spline Sans Mono

Alegreya is based on calligraphy, so it has a handmade rhythm that feels warmer and more human than a textbook. Its matching small-caps sans handles labels. Spline Sans Mono is clean and slightly rounded, and it stays quiet next to the expressive text.

Pairing 3

Built for legibility

Atkinson Hyperlegible Next & Mono · Young Serif

The Braille Institute designed Atkinson so that no two characters can be confused, and the Mono carries that into code: I, l, 1 and O, 0 are all unmistakable. Young Serif gives the titles a chunky, friendly voice. It's the least "booky" of the four, but the friendliest.

Pairing 4

Engineering manual

Archivo Expanded · Piazzolla · Martian Mono

Wide, heavy Archivo headings, like a technical manual or a NASA report, over Piazzolla, a sharp, compact serif made for reading. Martian Mono is wide and engineered, a code face with real presence. This is the boldest pairing, and the least like a book.
